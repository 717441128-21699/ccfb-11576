# 回滚网络同步测试台

单页面内运行两个对战客户端，用 **GGPO 风格回滚网络同步** 在模拟网络（延迟 / 抖动 / 丢包 / 乱序）下验证状态一致性，并提供回滚监视、分歧定位与参数调优。纯 TypeScript，无运行时依赖。

## 运行

```bash
npm install
npm run dev        # 打开 http://localhost:5173
npm test           # 单元 + 网络压测（含 5 分钟零分歧验收）
npm run build      # 类型检查 + 生产构建
npx vite-node scripts/stress-cli.ts   # 命令行直接跑 5 分钟极限压测
```

## 页面分区

| 分区 | 能力 |
| --- | --- |
| **对局** | 双客户端 Canvas 视图，整数网格、角色碰撞箱、攻击命中盒、血条；AI 自动对战或键盘手动 |
| **网络条件** | 单向延迟 / 抖动 / 丢包率 / 乱序率滑块，局域网/宽带/移动/极限预设，实时收发与实测延迟统计 |
| **回滚监视** | 累计回滚次数、重算帧数、最大重算耗时、卡顿帧；逐帧回滚帧数、重算 ms、双端预测深度三条曲线 |
| **同步检查** | 共同确认帧哈希比对、分歧总数；可注入物理/随机数/输入三类故障，定位**最先写错的变量**并归类 |
| **参数调优** | 输入延迟帧数、插值抹平帧数、最大预测窗口滑块；一键 18000 帧极限验收 |

## 关键设计

### 1. 整数网格确定性（`src/core/`）

- 1 像素 = 1000 网格单位，`WorldState` 的**每个字段都是整数**（测试 `全链路无浮点状态` 递归断言）。
- 物理只用 `Math.imul`/取整运算，禁止浮点字面量、`Math.random`、`Date` 进入状态。
- 随机数是帧确定的 32 位 LCG，`rngState` 本身是同步状态；每帧固定调用次数，挂机也对齐。

### 2. 回滚端点（`src/engine/rollback.ts`）

- 输入按**全局真实帧号 + inputDelay** 调度到统一模拟帧号，两端帧号空间一致。
- 远端输入缺失 → 空输入预测先行；迟到输入落在已模拟帧 → 回滚到该帧，从检查点确定性重算。
- 预测窗口耗尽 → 端点 `stall`，**每真实帧仍 tick 处理网络包**，输入到达后自然追帧。
- 故障执行输入按模拟帧持久化，回滚重算复用同一份，保证故障可复现、可定位。

### 3. 可靠输入层（`src/engine/session.ts` + `network.ts`）

50% 丢包下零分歧的核心。每个数据包携带：

- 本帧输入；
- **全部未被对端 ACK 的历史输入**（累积确认，收到 ACK 才清理）；
- 对端已收到的最高帧号 `ack`。

任何输入都会被反复重传直到确认，连续丢包也不会永久丢输入。独立的网络随机源与游戏 RNG 隔离，噪声不影响确定性。

### 4. 渲染插值（`src/engine/view.ts`）

回滚的权威状态会跳变，显示层维护独立的渲染状态，把 `x/y/vx/vy` 用 N 帧整数线性插值抹平（N 可调）；朝向、血量、计时器等离散字段立即对齐。插值只影响画面，绝不反馈进模拟。

### 5. 分歧定位（`src/core/hash.ts`）

FNV-1a 状态哈希逐帧比对；分歧时按模拟写入顺序逐字段扫描，报告第一个不一致变量，并归类：

- `rngState/tickEvents` → **随机数**（RNG 调用次数/参数分叉）
- `inputs[k].bits` → **输入处理**（采样/边沿错误，含与权威意图对照）
- 其余物理量 → **物理/碰撞结算**

## 验收结果

`200ms 单向延迟 + ±30ms 抖动 + 50% 丢包 + 10% 乱序，连打 18000 帧（5 分钟）`：

```
分歧次数   : 0
回滚次数   : ~13000
最大重算   : < 3 ms（一帧预算 16.7ms 内）
PASS：全程零分歧
```
