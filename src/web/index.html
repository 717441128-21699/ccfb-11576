牌局录入（PBN 格式）

格式：N: S.H.D.C 四家空格分隔，花色顺序为 黑桃.红桃.方块.草花，- 表示空门。

双明手最佳墩数（20 种定约）

每种将牌（♣♦♥♠NT）× 四个庄家，共 20 个结果。数字为该庄家双明手能拿到的墩数。

绿色 = 当前最佳出法； 红色 = 会丢墩，悬停可见具体丢墩数。

计分规则（WBF 标准复式赛）

  • 墩分：低花 ♣♦ 每墩 20，高花 ♥♠ 每墩 30，NT 首墩 40、其后每墩 30。
  • 成局线：墩分 ≥ 100。无局成局奖 300、有局 500；未成局部分定约奖 50。
  • 满贯：小满贯无局 500 / 有局 750；大满贯无局 1000 / 有局 1500。
  • 宕分：未加倍每宕一墩无局 50、有局 100；加倍/再加倍按专门罚分表。
  • 排名支持比赛分（Matchpoint）、平均 IMP（Butler）与队际 IMP。

计分与排名的完整逻辑与测试见 src/scoring/，可通过导入成绩 JSON 批量处理。

双明手引擎：Alpha-Beta + 置换表 + 等牌连张剪枝 + MTD(f)/PVS，纯 TypeScript 实现。
