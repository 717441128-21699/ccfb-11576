# 桥牌复式赛计分与双明手复盘工具

复式桥牌俱乐部的一体化工具: 导入每桌成绩 → 按局况计分 → 换算 IMP / 比赛分并排名;
并基于自带的双明手求解器, 对每副牌做逐墩复盘, 实时标注最佳出法与失误代价。

纯 TypeScript 实现, 前端 React + Vite, 核心引擎与 UI 解耦、可独立单测。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm test           # 运行全部测试 (含双明手 vs 暴力穷举对拍)
npm run build      # 类型检查 + 生产构建
```

打开后在「录入 / 导入」页点击 **载入示例数据** 即可体验完整流程
(8 副牌 × 4 桌, 含随机发牌, 可直接进入复盘)。

## 功能

### 1. 计分与排名 (`src/engine/scoring.ts`, `tournament.ts`)
- 完整定约分: 定约分、成局/满贯奖分、加倍与再加倍、宕墩罚分 (区分局况)。
- 双人赛: 比赛分 MP (Mitchell 两两比较)、交叉 IMP。
- 队式赛: 两桌净 IMP。
- 标准 16 副局况/庄家轮转; 并列同名次排名。
- TSV/CSV 导入, 表头中英文兼容, 定约支持 `4Sx`、`3NT`、`6Hxx`、`pass`。

### 2. 双明手求解器 (`src/engine/dds.ts`)
对每副牌计算四家分别领出、五种定约 (C/D/H/S/NT) 共 20 个最优墩数。

- **零和 Alpha-Beta 搜索**, 评估值为 NS 方在剩余牌中的墩数。
- **置换表**: 开放寻址 + 线性探测, 双 32 位 Zobrist 校验 (64 位等效) 防碰撞,
  存 EXACT/LOWER/UPPER 边界与最佳着法; 同一定约四个领出共享热表。
- **等价牌合并剪枝**: 同花色相邻连张 (中间无别家持牌) 只搜索一张代表牌;
  跟牌时铁定赢不了的花色整组只出最小牌; 同伴已锁定赢墩时的最小牌剪枝。
- **终局知识**: 每家剩 1 张时直接判墩, 不再递归。
- 墩结算时对 Alpha-Beta 窗口做对应平移, 保证边界与置换表 flag 正确
  (这是本实现调试中定位到的关键正确性要点)。

### 3. 逐墩复盘 (`src/workers/review.worker.ts`, `src/ui/DealReview.tsx`)
- 会员点开一副牌, 逐张出牌。
- 每个轮到的座位, 后台 Worker 用双明手引擎评估**所有合法着法**的最优墩数,
  牌面上高亮最佳出法, 非最佳着法标注「丢 N 墩」。
- 出牌记录区分最佳/失误; 同一将牌的置换表随复盘推进持续复用。

### 4. 并行 Worker
- `strain.worker.ts`: 5 个定约各一个 Worker 并行求解, 避免阻塞主线程。
- `review.worker.ts`: 复盘着法评估在后台线程执行, UI 显示计算状态。

## 正确性验证

求解器与一个**不带任何剪枝的暴力穷举极小极大** (`src/engine/brute.ts`) 对拍:
- 每家 3 张: 50 副随机牌 × 5 定约 × 4 领出, 全部一致。
- 每家 4 张: 12 副随机牌全对比一致。
- 墩中 (非墩首) 残局状态、含将吃/垫牌的混合花色局面均覆盖。
- 另有确定性手工牌例 (全大将牌吃通等) 与 PBN 往返测试。

计分模块对成局、满贯、加倍、宕墩、IMP 档位、比赛分、队式 IMP 等逐一断言。

## 性能现状 (诚实说明)

引擎在**小残局上很快** (每家 9 张约 0.7 秒, 吞吐约 150 万节点/秒),
但**完整 13 张牌的单次求解在纯 TS 下为分钟级**, 尚未达到「20 个结果 < 3 秒」的目标。

已实测的安全优化 (置换表最佳着法提示、赢墩能力排序、等价/垫牌剪枝、终局知识、
可配置大 TT) 把分支因子压到约 6–8, 但与 Bo Haglund DDS 这类 C++ 引擎的毫秒级
仍有数量级差距, 主要差在更深的跨手牌等价剪枝与原生执行速度。
当前通过 **5 Worker 并行 + 异步进度展示** 保证界面不卡死, 计算在后台完成。

后续可继续投入的方向:
- 实现 Bo Haglund 式更完整的 equalCard / 领出等价类 (需持续用暴力对拍守护正确性);
- 残局预计算表 (少墩局面离线缓存);
- 将热点求解器迁移到 WASM (Rust/C++) 并复用同一套 TS 接口。

## 目录结构

```
src/
  engine/      纯逻辑引擎 (无 DOM 依赖)
    cards.ts     牌型/位运算/PBN/发牌
    dds.ts       双明手 Alpha-Beta + 置换表
    brute.ts     暴力穷举参考实现 (仅测试对拍)
    scoring.ts   定约分 / IMP / 比赛分
    tournament.ts 比赛数据模型 / 导入 / 聚合排名
    review.ts    复盘状态机 (可单测)
    deal.ts      小残局发牌 (测试用)
  workers/     strain / review 两个 Web Worker
  state/       前端状态、Worker 客户端、示例数据
  ui/          React 组件与样式
tests/         Vitest 测试
```
